ContentBlocks includes utility snippets for conditional front-end logic.

- [cbHasField](cbHasField)
- [cbGetFieldContent](cbGetFieldContent)

**Note:** These snippets use v1 terminology ("field" instead of "block") but work with ContentBlocks 2 block data where applicable.

Block identification is different from v1 field IDs, now requiring the block name. On upgrade you will need to adjust your snippet calls.
