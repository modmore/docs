When extending ContentBlocks, you have the option to create custom input types (which contain _content_), as well as custom plugins (which contain manager-side _behavior_).

This section is about **Custom Plugins**. To learn more about built-in plugins, see [plugins](../../03_Plugins).

Plugins are written as a single JavaScript file/class and can be built to support block, layout, or canvas-level instantiation. There are lots of events you can listen to (or dispatch) and in-built utilities to build on.
