## Main inputs

The fields shown directly on the block are the primary content: text, images, links, and so on. Edit these inline.

## Drawer

When you select a block, an expandable **drawer** may appear below the main inputs. This holds secondary settings that do not need to be visible at all times, like style options, alignment, or optional fields.

Only a single drawer is open at a time, so click anywhere else to close it again.

## Settings modal

Some blocks have a **cog icon** in the toolbar. Click it to open a settings window with additional options. Changes apply immediately as you edit; click Save or close the modal when done.

Layout rows can also have a settings modal for layout-level options.

## Conditional fields

Some blocks show or hide fields depending on your other choices (for example, selecting "Video" may reveal a URL field while hiding an image upload).
