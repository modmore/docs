## Adding a block

1. Click inside a layout column where you want content.
2. Click the + button on the left side of the column; when hovering it will say "Insert Block".
3. Browse or search for the block type you need.
4. Click the block to insert it and add your content into it.

## Adding a layout

1. Click **Insert Layout** in between existing layouts or at the top and bottom of the page.
2. Choose a layout structure from the modal. Your site's builder determines the available layouts. Some layouts may be prefilled with content, while others will be empty structure only.
3. Add blocks to the new layout's columns. Some layouts already contain blocks when they are inserted. Edit or remove those the same way as blocks you added yourself.

## Reordering

- **Blocks:** drag a block by its handle (in the toolbar) to move it within a column, or to another column if your layout allows.
- **Layouts:** use the up and down arrows in the toolbar of a layout to reorder them.

## Removing

Select a block or layout and use the delete icon in the toolbar.

## Unsaved changes

Edited blocks may show a change indicator until you save the resource. Always save before leaving the page.
