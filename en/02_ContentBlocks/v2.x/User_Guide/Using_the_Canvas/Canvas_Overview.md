## Layouts

A **layout** is a row structure with one or more **columns**. For example, a "Two columns" layout has a left and right column where you can place blocks independently. The available layouts are specific to your site.

To add a layout, use the **Insert Layout** button. Choose from the layouts your site builder has made available.

## Columns

Each column in a layout holds blocks stacked vertically. You can have different block types in each column: text in one column and an image in another, for example.

## Blocks

**Blocks** are the actual content: headings, paragraphs, images, videos, and so on. Each block type has its own inputs (fields) for the data you enter. Available blocks are specific to your site.

Blocks live inside layout columns. A page typically has one or more layouts, each containing one or more blocks per column.

## Toolbar

When you select a block or layout, a toolbar appears with actions such as:

- **Move** — drag to reorder
- **Settings** (cog icon) — open additional options when available
- **Delete** — remove the block or layout
- **Fullscreen** — expand for focused editing (when enabled)

Some blocks also show a **drawer** below the main inputs when selected, that's an expandable area with extra settings.
