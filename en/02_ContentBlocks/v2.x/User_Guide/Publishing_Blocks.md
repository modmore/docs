Some sites enable **block-level publishing**, letting you control when individual blocks appear on the front-end.

[TOC]

## Published state

Each block can be **published** or **unpublished**:

- **Published** blocks appear on the live site.
- **Unpublished** blocks are hidden from visitors but remain visible (with a slated background) in the editor so you can still edit them.

## Opening publishing controls

Click the **eye icon** in a block's toolbar to open the publishing settings.

For blocks inside a repeater (a list of similar items), each row has its own eye icon.

## Scheduling

You can schedule blocks to publish or unpublish automatically:

- **Publish on** — set a date and time for the block to become visible.
- **Unpublish on** — set a date and time for the block to be hidden.

Leave a schedule empty if you want to control visibility manually with the published toggle.

## Saving

Publishing changes are saved when you save the resource. Scheduled blocks show an amber indicator in the editor when a future publish or unpublish date is set.

## Front-end

Visitors only see published blocks. Scheduled changes take effect automatically — you do not need to re-save the page when the scheduled time arrives.
