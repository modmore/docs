The `Debug` plugin shows the serialized canvas data below the canvas in the manager. Enable it on a canvas when you want to inspect the raw data while editing.

It is canvas-only. Block and layout configurations ignore it.

[TOC]

## Accepted options

- None

## Example canvas

Add it to your [Canvas Configuration](../01_Configuring_Content/Canvas_Configuration):

```json
{
    "plugins": {
        "Debug": {}
    }
}
```
